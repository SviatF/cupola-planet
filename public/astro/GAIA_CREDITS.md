# Gaia EDR3 all-sky colour map — credit & reuse

The file `gaia-edr3-sky.webp` is a size-optimized **adaptation**
(format conversion and lossy compression) of a colour/brightness map produced
from ESA Gaia's Early Data Release 3, in equirectangular Galactic coordinates.

**Credit:** ESA/Gaia/DPAC. **Acknowledgement:** A. Moitinho.

**Original:** [The colour of the sky from Gaia's Early Data Release 3 — equirectangular map](https://www.esa.int/ESA_Multimedia/Images/2020/12/The_colour_of_the_sky_from_Gaia_s_Early_Data_Release_32)

**Mirror (pinned source bytes):** [Wikimedia Commons file](https://commons.wikimedia.org/wiki/File:Interactive_map_of_the_sky_from_Gaia%E2%80%99s_Early_Data_Release_3_ESA25364661.png)

**Changes made:** Image decoding, RGB conversion, WebP compression
(quality 76); no stars, colour patches, or nebulae were artificially added
to the adapted source file. In the CUPOLA renderer, image brightness and
opacity are reduced to match the background scene.
